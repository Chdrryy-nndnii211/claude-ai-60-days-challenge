# Day 2 - 60 Days Claude Challenge

## What I worked on
Today I learned about Prompt Engineering — the difference between weak prompts and engineered prompts.

## Key Learnings
- A weak prompt like "Write about marketing" gives generic output.
- An engineered prompt (specific, structured, with clear goals) gives much better, focused output.
- Good prompts should include: audience, goal, tone, and constraints.

## Prompts I used
1. "Write about marketing."
2. "Write a focused, structured prompt with clear goals..."

## Reflection
Prompt engineering is the real skill multiplier when using AI tools like Claude.

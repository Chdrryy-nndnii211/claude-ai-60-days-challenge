# 🌍 Personal Environmental Health Analyzer

An interactive web dashboard that analyzes **AQI, PM2.5, PM10, and water quality** to provide personalized environmental health insights.

## ✨ Features

* 📊 AQI, PM2.5 & PM10 analysis
* 🏙️ City comparison and rankings
* 📈 Interactive charts and filters
* 🌬️ Air & 💧 water quality scores
* 📝 Environmental Health Score (0–100)
* 🚦 Health-risk indicators and AQI categories
* 💡 Personalized health & lifestyle recommendations
* 📱 Responsive modern dark-theme UI

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Data Visualization

## 🎯 Key Insights

* Cleanest & most polluted cities
* Average and highest AQI
* Environmental trends
* Anomalies and important observations
* Air, water, hair & skin risk analysis

## 🚀 Run Locally

```bash
git clone https://github.com/your-username/personal-environmental-health-analyzer.git
```

Open `index.html` in your browser or use **VS Code Live Server**.
